# Speedtest — замер скорости скачивания

Консольный скрипт на Python, который делает 10 последовательных GET-запросов
к указанному URL, дожидается полного ответа на каждый и считает статистику:
среднее время запроса, общий объём скачанных данных и скорость скачивания.

## Требования

- Python 3.10+
- библиотека `requests`

## Установка

```powershell
# 1. Клонируйте репозиторий
git clone https://github.com/gelcen/easy-test.git
cd easy-test

# 2. (Рекомендуется) Создайте виртуальное окружение
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3. Установите зависимости
pip install -r requirements.txt
```

## Запуск

```powershell
python speedtest.py <url>
```

Пример — скачивание 25 МБ с тестового сервера Cloudflare:

```powershell
python speedtest.py "https://speed.cloudflare.com/__down?bytes=25000000"
```

В качестве аргумента подойдёт любой URL, отдающий файл, например ссылка
на картинку или архив.

> URL берите в кавычки, если в нём есть символы вроде `?` и `&` —
> они имеют особый смысл для командной строки.

## Пример вывода

```
Запрос 1/10... 3.64 с, 23.84 МБ
Запрос 2/10... 5.68 с, 23.84 МБ
...
Запрос 10/10... 3.28 с, 23.84 МБ

Успешных запросов:     10/10
Среднее время запроса: 3.89 с
Всего скачано:         238.42 МБ
Скорость скачивания:   6.13 МБ/с
```

## Единицы измерения

- **Время** — секунды (с), с точностью до сотых.
- **Объём** — мебибайты (МБ), где 1 МБ = 1024 КБ = 1 048 576 байт.
- **Скорость** — МБ/с: общий объём скачанных данных, делённый
  на суммарное время всех успешных запросов.

## Как это работает

1. URL передаётся аргументом командной строки (`sys.argv`).
2. В цикле 10 раз выполняется последовательный GET-запрос через `requests.get`.
   Запрос N+1 начинается только после полного скачивания ответа на запрос N.
3. Каждый запрос замеряется секундомером `time.perf_counter()`,
   объём ответа — через `len(response.content)`.
4. Неудачные запросы (ошибки сети, HTTP-ошибки, таймаут) пропускаются
   и не участвуют в статистике.
5. Скорость считается как суммарный объём / суммарное время успешных запросов.
